Como engenheiro de metadados e arquiteto de prompts, o objetivo é extrair a estrutura de dados adjacente e a semântica visual dessa transcrição, convertendo elementos soltos de interface e intenções narrativas em uma estrutura legível por máquina.

Para que uma IA compreenda e execute instruções baseadas em uma identificação visual, precisamos encapsular os dados voláteis (números na tela, gráficos) em chaves de metadados estruturadas.

Abaixo está o design da arquitetura de metadados e o script final gerado a partir do texto fornecido.

---

## 1. Arquitetura de Meta-dados (Schema de Extração)

Esta estrutura funciona como a tipagem de dados que a IA lerá para identificar cada componente visual citado na transcrição:

```json
{
  "screen_elements": {
    "metrics_panel": {
      "subscribers": "integer",
      "total_adsense_earnings": "currency",
      "average_rpm": "currency"
    },
    "visual_charts": {
      "growth_trend": "string (direction/slope)",
      "baseline_reference": "string (position_relative_to_mouse)"
    },
    "product_overlay": {
      "course_price": "currency",
      "course_total_sales": "currency"
    }
  },
  "narrative_core": {
    "speaker_identity": "string",
    "thesis": "string",
    "analogies": "array"
  }
}

```

---

## 2. Script Estruturado para IA (Prompt / Input de Parâmetro)

Este é o script reescrito na direção do texto original, mas traduzido em blocos lógicos estruturados que qualquer LLM (Modelo de Linguagem) consegue processar instantaneamente para gerar respostas, criar relatórios ou analisar o comportamento visual do vídeo.

```markdown
# IA INPUT SCRIPT: ANÁLISE DE DASHBOARD E MENTORIA DE INFOPRODUTOS

## [CONTEXTO DA TELA / IDENTIFICAÇÃO VISUAL]
- **Elemento_Visual_01 (Painel Principal):** Gráfico de crescimento do AdSense mostrando curva ascendente na minutagem [0:18]. Indica acúmulo de 46.000 inscritos no canal.
- **Elemento_Visual_02 (Métrica Estática):** Caixa de texto/faturamento exibindo o valor exato de R$ 28.723,14 acumulados nos últimos 2 anos [2:12].
- **Elemento_Visual_03 (Filtro Temporal):** Tela filtrada nos "Últimos 365 dias" exibindo um número mágico de RPM médio de R$ 16,32 [6:56 - 8:19].
- **Elemento_Visual_04 (Gráfico de Tendência):** Linha de visualizações nos últimos 365 dias demonstrando uma tendência de queda, operando abaixo da linha de referência do mouse [11:17 - 11:34].
- **Elemento_Visual_05 (Faturamento Alternativo):** Tela de vendas da plataforma de infoprodutos exibindo faturamento de R$ 28.736,00 no primeiro ano e R$ 15.000,00 no período subsequente, totalizando ~R$ 40.000,00 líquidos após reembolsos [25:16 - 26:04].

## [NÚCLEO NARRATIVO / DIRETRIZES DE TEXTO]
- **Identidade do Apresentador:** Joba (Especialista em YouTube com 10 anos de experiência).
- **Tese Central:** O YouTube é lento e focar exclusivamente no ganho de AdSense (visualizações/RPM) é uma estratégia amadora. Canais sustentáveis dependem de múltiplas fontes de renda e conversão de infoprodutos (mesmo de ticket baixo como R$ 5,90).
- **Analogia Operacional:** O crescimento no YouTube não é uma corrida de 100 metros rasos; é uma maratona de consistência. Profissões digitais exigem processos complexos e invisíveis, assim como cursar Direito e passar na OAB.

## [PARÂMETROS DE EXECUÇÃO PARA A IA]
Utilizando os dados visuais e analíticos acima, execute a seguinte tarefa:
1. Valide a correlação matemática apresentada na tela: Demonstre como um RPM de R$ 7,00 em 200.000 visualizações resulta em R$ 1.400,00, provando a limitação do AdSense puro.
2. Contraste o ganho de AdSense (R$ 28.723,14 com 1.5M de views) contra o ganho do infoproduto de baixo ticket (R$ 40.000,00 com menor tráfego), estruturando a lógica de que "Vender é Servir e Gerar Valor".
3. Mantenha o tom realista, direto e focado no processo (anti-fórmula mágica).

```

---

## Como isso resolve o problema?

Ao alimentar uma IA com o formato do item 2, você remove a ambiguidade da transcrição falada. A IA passa a entender exatamente que:

* O valor de R$ 28.723,14 pertence à métrica visual de **AdSense**.
* O valor de ~R$ 40.000,00 pertence ao **infoproduto de R$ 5,90**.
* A posição do mouse na tela serve como um **indicador de benchmark** para a queda do algoritmo.

Isso permite que o modelo gere respostas analíticas perfeitas baseadas nos parâmetros exatos do vídeo original.
